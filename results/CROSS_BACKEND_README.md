# Cross-Backend Run Outputs

Notebook `04_cross_backend_comparison.ipynb` generates:

- `cross_backend_n4_h1_run.csv` — compact comparison table;
- `cross_backend_n4_h1_run.json` — structured results including term-level estimates and device metadata.

These files are intentionally generated by execution rather than pre-populated with invented device-derived values.

The deterministic scientific reference remains:

- exact ground-state energy: **-4.7587704831**;
- variational statevector energy: **-4.7575478600**.

The cross-backend experiment then measures how finite-shot and device/noise effects move the observed energy away from those reference levels.
