# AfriQBench MVP Roadmap

## Month 1 — Benchmark specification and reference implementation

- finalize TFIM benchmark protocol;
- define parameter ranges and observables;
- validate exact classical reference calculations;
- establish testing and contribution workflow;
- engage with the Metriq community before freezing interfaces.

**Milestone:** public technical specification and working reference solver.

## Month 2 — Quantum benchmark prototype

- implement circuit-generation workflow;
- define measurement procedures;
- implement scientific and resource metrics;
- create reproducible benchmark configurations;
- validate on ideal simulation.

**Milestone:** end-to-end simulator benchmark prototype.

## Month 3 — Noisy execution and Metriq alignment

- add noisy-simulator experiments;
- implement reproducibility checks;
- develop result serialization;
- align execution/result structures with Metriq conventions.

**Milestone:** Metriq-compatible benchmark candidate.

## Month 4 — Hardware and mitigation experiments

- execute on accessible quantum hardware where available;
- collect structured benchmark records;
- compare backends;
- develop a Mitiq-based mitigation notebook.

**Milestone:** cross-platform benchmark dataset.

## Month 5 — Open release and upstream contribution

- finalize code, tests, documentation, and notebooks;
- release benchmark data;
- submit an appropriate Metriq proposal, issue, or pull request;
- run a community validation session;
- publish a final technical report.

**Milestone:** public release and upstream contribution.
